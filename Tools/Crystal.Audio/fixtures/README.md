# Audio fixture (not game art)

`tone.wav` is a generated 120ms 440Hz PCM sine for Client.Linux `--play-sound` proof only.

Operator Crystal Sound packs (`Settings.SoundPath`, typically `./Sound/` or mirfiles `Sound/`) stay **outside git**. Point `--sound` or `CRYSTAL_SOUND` at a `.wav` file or that directory. Do not vendor the pack.
